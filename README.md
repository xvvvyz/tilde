# Tilde

Tilde is a minimal browser homepage for pro web surfers.

## Usage

Type or tap anywhere, then press <kbd>Enter</kbd>.

| Input            | Goes to                                                        |
| ---------------- | -------------------------------------------------------------- |
| `g`              | [github.com](https://github.com)                               |
| `g tilde`        | [GitHub search for tilde](https://github.com/search?q=tilde)   |
| `g/xvvvyz/tilde` | [github.com/xvvvyz/tilde](https://github.com/xvvvyz/tilde)     |
| `tilde`          | [DuckDuckGo search for tilde](https://duckduckgo.com/?q=tilde) |
| `example.com`    | [example.com](https://example.com)                             |

<kbd>↓</kbd> and <kbd>↑</kbd> pick a suggestion, <kbd>Tab</kbd> completes it,
<kbd>Esc</kbd> closes.
